# Support

## Questions

Discussions are not enabled in this repository. Ask questions about how to use Bastion in [Discussions in the Bastion hub](https://github.com/Myrpisset/bastion/discussions).

## Bugs and requests

Open an issue in the affected repository when you can describe a reproducible bug or a concrete request. If it concerns every platform, open it in the [Bastion hub](https://github.com/Myrpisset/bastion).

## Security problems

Never report vulnerabilities, tokens or keys publicly. Follow [SECURITY.md](SECURITY.md).

## Scope

Bastion is maintained as time allows. A question or report does not guarantee a response time.
